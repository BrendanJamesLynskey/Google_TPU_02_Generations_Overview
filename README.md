# Ten Years of TPUs &mdash; v1 to Ironwood

Spec sheet for every TPU generation from the 2015 inference chip through Ironwood (TPU v7). Process node, peak compute, HBM, ICI, pod size, role, and what each one unlocked. Includes log-scale per-chip compute chart, HBM-capacity chart, pod-size table, and an interactive generation-comparison explorer.

**Live site:** https://brendanjameslynskey.github.io/Google_TPU_02_Generations_Overview/

Part of the [Google TPUs series](https://github.com/BrendanJamesLynskey/LLMs#hardware--inference).
